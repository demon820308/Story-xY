## 细纲（第 22 章）

### 第 22 章：他没回来
- 核心事件：江晨批假出营，赴邻市老干休所家属院听谭守义把压了五十年的故事讲完并录音，第一次知道《离别开出花》要写的到底是什么。
- 字数目标：2400 字
- 字数口径：visible_chars_v1
- 阶段位置：第一卷后段 · 第3阶段（任务三循环）第2章；本章承担「揭示与补给」：上一章立起倒计时、授权与素材入口，本章把素材真正拿到手——用一次出营的实成本换一段能落笔的真实故事，把「离别」主题从主角的构想推进成有实指的内容
- 单元ID/位置：L1-03；单元内第2拍（揭示与补给）
- 目标情绪：紧迫（批假出营的成本）→ 陌生的安静（老干休所家属院）→ 累积的克制（老兵的白描）→ 哽住（铁盒打开那一刻）→ 沉重的托付 → 回程上的创作冲动（词眼到手）
- 主角目标/关键选择：拿到能写词的真实故事；关键选择＝不当采访者、不导不写、只听（不打断、不替老兵总结），以及看见那封信时把手收回来（尊重老兵的分寸，也把「信的去处」留给后章）
- 章节定位：推进
- 本章结构公式：批假出营（成本前置）＋ 老干休所家属院（场景建立）＋ 五十年的一段旧事（揭示主体）＋ 压在铁盒里的那封信（物证冲击）＋ 回程路上的四个字（尾钩）
- 章首钩子：假条——周薄森只问一句「一天够吗」，江晨答「来回一整天」，成本当场落地；不用系统播报开场
- 爽点：本章无打脸爽点，走本书的泪目模块（老兵故事）；军宣爽点延迟到第25-26章的作品兑现，本章只给「素材到手」的获得感与读者的情绪释放
- 本章标价：一天（十四天里抽掉一天）；两百里（往返成本）；五十年（故事的时间重量）
- 闭环状态：获得（故事与那封没寄出的信）→ 使用（录音笔录下）→ 见效（词眼落地，江晨知道该写什么了）→ 估值（第25章现场弹唱兑现）
- 本章禁止提前释放：不写《离别开出花》的歌词成品（江晨还没动笔，只在末尾确认方向）；不写《离别开出花》的作品效果、传播数据与开放日现场；不出现陆振国、其账号与任何具名质疑方；不写钟嘉嘉的军方家庭背景与培养安排；不写出那封信的最终去处（交给谁、怎么交）；韩雪只在口述里被提到，不出场；不写吴伟公诉结果；不出现齐首长
- 写手自由区：邻市老干休所家属院的环境白描（门牌、楼道、墙上戈壁年代的黑白合影、搪瓷缸）、谭守义讲故事时的停顿与手上动作、江晨插话的分寸与次数、录音笔放在哪、回程路上的江晨状态与手机里那四个字
- 契约风险：契约安全（素材由老兵自愿给出，主角不索取不代决；信的处置权留给作者与后章；本章只回收 F054 与 F057，不动 F024、F055、F056 的兑现章）

#### 内容概括（五段式）
- 起因：早上江晨到团部批假，周薄森问「一天够吗」，江晨说来回一整天；车开出营门两百多公里，到邻市老干休所家属院，谭守义早早在楼下等着
- 发展：客厅里江晨说明来意——不采访、不写稿，只想听他讲一遍；录音笔放在茶几上。谭守义从1968年入伍讲起，讲到同班战友韩树生，讲到1974年秋戈壁的一次试验事故
- 转折：韩树生出事前一周托他寄一封给母亲的家书，信里写着「等我回家」；事故后信被保密审查扣下，退还时韩母已经收到通知——他怕这四个字再扎一次老人，就一直没寄，一压五十年
- 高潮：谭守义从柜子里拿出铁盒，里面是一封折痕发黄的信；江晨伸手到一半又收了回去；谭守义说「我讲了五十多年，没跟人讲全过」「她不在了，我该交给谁」
- 结尾：回程路上江晨把录音拖到「等我回家」那一句，在手机备忘录里打下这四个字；他没有动笔写词，但已经知道该怎么写了；给周薄森发消息：明天回团，要那份审核清单

#### 情节安排（多线）
- 主线推进：L01 从「任务三发布＋主题定为离别＋钢琴首次可用」推到「离别主题拿到实指素材，写词前提成立」
- 辅线推进：L03 从「拿到地址与『没人听全过』」推到「老兵故事被完整讲出并录音，那封没寄出的信同时被读者与江晨知道」
- 事件线 / 任务线：批假 → 往返两百里 → 客厅录音 → 故事揭示 → 铁盒里的信 → 回程定词眼
- 任务卡点：江晨要做歌 → 卡在「有伴奏没有词」，硬指标之外还差一块真东西 → 出营一天求素材 → 听完故事，卡点解除（词眼到手）→ 第23章再撞审核清单
- 感情线 / 关系线：无显性；江晨与谭守义从「线上邀约」变为「面对面听完一段压了五十年的话」；钟嘉嘉只以一条消息出现（问他到哪了），不推进身份线
- 逻辑线：任务三只给硬指标 → 伴奏有了词还没有 → 老兵说「没人听全过」 → 江晨上门只听不导 → 故事讲完、词眼落地 → 回去写词（第25章兑现）

#### 人物关系和出场顺序
- 出场顺序：江晨、周薄森（批假，一句台词）、驾驶员（一次性，合并描写）、谭守义、客厅里的老照片（场景道具）
- 镜头准入：场1 团部办公室（周薄森台词位短、江晨动作位）；场2 车里与老干休所楼下（江晨视角，环境位，不给长独白）；场3 谭守义客厅（谭守义主台词位、江晨听与插话位、录音笔作为在场道具）；场4 回程车内（江晨独处＋手机）
- 人物关系变化：江晨与谭守义从「一句客气邀约」变为「面对面听完一段压了五十年的话」；江晨与这部作品从「有伴奏没词」变为「知道该写什么了」
- 视角/信息差：读者与江晨同步第一次听到这件事；谭守义只做白描（「他没回来」），不替读者下结论；钟嘉嘉的军方背景仍是作者真相，不触碰；韩雪只在口述里被提到，不出场
- 信息差触发点：点7，谭守义讲事故时只用「他没回来」四个字，读者靠白描自己补全分量，江晨当场停住
