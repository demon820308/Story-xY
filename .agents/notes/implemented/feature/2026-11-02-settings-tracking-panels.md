# Agent Note: 设定与追踪看板入口与呈现整改（M33-M36）

Status: implemented
Date: 2026-11-02
Related: M33-M36, A39-A42

## Problem

右侧栏页签按钮「世界观与核心／核心设定与人设」「追踪看板／小节大纲与进度」及其打开的设定与追踪面板存在以下问题：
1. 按钮随模式换名但无模式标识，认知成本高；已选页签再次点按无反应无法收起面板；未选态对比度不足；图标语义混乱且存在 `🎪` 语义错误与 `🎯` 混用。
2. 设定面板靠三个固定目录硬分，长篇根目录文件（如「题材定位.md」）全被误归入「体系」；横向胶囊截断致多角色查找困难；短篇对标文件混装硬编码前缀；空状态缺乏一键生成入口且含有黑话。
3. 追踪面板缺少长篇结构化状态展示，未呈现 `_tracking-state.json` 中的超期与活跃伏笔；窄栏内渲染宽表导致整页横滚；文档缺乏修改时间与标题元信息。

## Decision

落地 M33-M36 设计整改：
1. **M33 按钮与页签**：
   - AppShell 右侧栏模式条内嵌模式徽章（`[长篇]` / `[短篇]`），降低同位换名认知成本。
   - 点按已激活页签支持立即收起右侧面板；未选态采用 WCAG AA 高对比配色与描边。
   - 追踪页签接入 `_tracking-state.json` 状态探测，伏笔超期时显示警告计数徽章。
   - 建立统一 SVG 图标集（`StoryIcons.tsx`），全项目彻底移除 `🎪`，解耦 `🎯`。
2. **M34 设定面板**：
   - 抽象 `lib/story-setting-category.ts` 统一判定题材、角色、世界观、势力、体系，将 `题材定位.md` 正确归入题材分类。
   - 长篇设定支持即时搜索与过滤，解决多角色查找难题；筛选切换时自动联动预览第一项。
   - 短篇面板区分核心设定与对标参考独立分组；空状态提供无黑话的「生成核心设定」一键按钮。
3. **M35 追踪面板**：
   - 长篇顶部建立结构化状态条，直读 `_tracking-state.json` 输出进度章、活跃伏笔、超期告警与最新角色动态。
   - 点击超期伏笔警示一键跳转选中伏笔状态表；短篇指标条保持原样不回退。
   - 空状态提供「初始化追踪骨架」一键按钮。
4. **M36 内容呈现**：
   - `FileViewer` 内置紧凑表格容器（`story-compact-table`），实现局部水平滚动与首列冻结，根除整页横滚。
   - 预览顶部呈现文档名与修改时间（`mtime`）；保留 `watchEnabled` 实时同步机制。

## Alternatives considered

- **仅在面板内加搜索，不改变分类 taxonomy**：最强理由是修改更小。不采用：根目录「题材定位.md」仍会被误分类为「体系」，导致分类失真；必须采用对齐 skill 设定的统一分类器。
- **改用外部图标库依赖**：最强理由是图标资源丰富。不采用：直接在 `StoryIcons.tsx` 中编写 10 枚纯 SVG 轻量组件，零新依赖开销。
- **将追踪面板重构为独立图表 Canvas**：最强理由是图形视觉效果更好。不采用：开发成本高且脱离 Markdown 底座；采用「顶部结构化指标条 + 底部原生文件视图」的双层方案，兼顾直观性与底层编辑能力。

## Consequences

- 收益：页签交互自然可收起，未选态清晰，图标语义单一纯净；设定与角色检索定位速度大幅提升；追踪面板具备真正的结构化洞察能力，伏笔超期一眼可见并可直达；窄栏读表体验大幅改善，首列冻结不迷航。
- 代价：AppShell 和面板需在挂载时发起轻量状态探测；表格第一列采用 sticky 定位，需保证背景色与主题色严格对齐。
